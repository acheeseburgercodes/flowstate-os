# FlowState OS — animated product advertisement

New 36-second product film with kinetic typography, animated specialist cards, moving UI panels, a dark/light reveal, original instrumental music, and real browser interaction footage. The composition is rendered at 1080p / 60 FPS; no narration.

Download `FlowState-OS-motion-ad.mp4` for the finished video. Download and open `FlowState-interactive-preview.html` for playback, scrubbing, and music controls. The preview contains its own media; its separate Live application view requires the local FlowState web server on port 5173.

The film demonstrates the interface and previously verified local jobs. It does not claim live Discord verification or Switch-controller-managed agent execution. Application functionality and setup instructions remain in the main README.
